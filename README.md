# 蔗糖的注意力闸门~

群聊注意力硬闸门：AI 平时完全不可见群消息（不进上下文、不写记忆），被 @ 后开启注意力窗口，窗口内可见所有群消息并免 @ 回复；窗口到期 AI 自查上下文决定继续还是退出，退出后重新封闭，等待下一次 @ 唤醒。

## 行为

- **封闭期（默认）**：所有群消息在插件处理阶段被拦截，主 LLM / 记忆 / 好感度统计均不可见（零 token）
- **唤醒**：被 @ 后开启窗口（默认 30 秒），并注入最近 20 条群聊记录作为临时上下文（仅本次回复可见，不沉淀为记忆）
- **窗口期**：普通消息注入参与纪律——话题不需要插嘴或对话已结束则输出静默标记（插件拦截不发）；窗口期间再次被 @ 不重置计时
- **到期自查**：携带窗口内聊天记录独立调用 LLM 判断"继续 / 退出"，继续则续期，退出则封闭；总上限防无限续杯

## 指令

- `/闸门 status` 查看状态
- `/闸门 open [秒]` 手动开窗
- `/闸门 close` 手动关闭

## 提示

- 窗口状态存于内存，重启后所有群回到封闭态（安全默认）
- `groups` 配置留空 = 对所有群生效
